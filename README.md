# Chefe AXM — 01-Mesa

Esta pasta é um site independente. Abra index.html com Live Server ou sirva esta pasta via HTTP. Aceda ao painel de demonstração pelo rodapé.
Na Vercel, seleccione esta pasta como Root Directory. A configuração está em vercel.json; não há .env ou dependências para instalar.
Menu, preços, fotografias, pedidos, estatísticas, trabalhadores e tarefas são demonstrativos. Os dados são locais ao navegador e não são partilhados. Pode exportar/importar JSON em Personalizar.
A identidade e os textos podem ser alterados em Personalizar. No título do hero, use | para separar as duas linhas e destacar a segunda.
